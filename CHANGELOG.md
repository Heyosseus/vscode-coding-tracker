# Change Log

All notable changes to the "vscode-coding-tracker" extension will be documented in this file.

## [0.0.1] - 2024-10-18

### Added

- Real-time coding time tracking with status bar indicator
- Automatic idle detection (configurable timeout)
- Batch synchronization with remote API
- Local data persistence for offline support
- Commands for viewing statistics, resetting data, and opening settings
- Configurable API URL, API Key, idle timeout, and batch size
- Activity detection for file changes, saves, editor focus, and window focus
- Automatic retry for failed API uploads

### Features

- Shows current session time in status bar with clock icon
- Tracks project name and current file path
- Persists data across VS Code restarts
- Privacy-focused: no third-party data collection
